# نظام تحليل درجات الصف السادس 

تطبيق ويب (Flask + HTML) يحلل درجات طلاب الصف السادس: نسب مئوية، مستويات، ترتيب على مستوى الفصل والصف، رسوم بيانية، وتصدير للنتائج.

## التشغيل محليًا
```
pip install -r requirements.txt
python make_sample.py      # اختياري: ينشئ ملفات بيانات تجريبية
python app.py
```

## صيغة ملف الدرجات
الصيغة الأولى — شيت لكل فصل (اسم الشيت هو اسم الفصل):

| اسم الطالب | الدرجة |
|-----------|--------|
| محمد أحمد | 45     |

الصيغة الثانية — شيت واحد بعمود إضافي للفصل:

| اسم الطالب | الفصل | الدرجة |
|-----------|-------|--------|
| محمد أحمد | 6/ج   | 45     |

- أسماء الأعمدة تُكتشف تلقائيًا بالعربي أو الإنجليزي.
- الأرقام العربية (٤٥) مقبولة.
- زر "تحميل نموذج إكسل جاهز" في الصفحة يوفر ملفًا بالصيغة الأولى.

## الميزات
- إدخال الدرجة الكلية وحساب النسبة المئوية لكل طالب
- تصنيف المستويات (ممتاز / جيد جدًا / جيد / مقبول / غير مجتاز) بحدود قابلة للتعديل
- ترتيب الطلاب على مستوى الفصل وعلى مستوى الصف كامل (المتساوون يأخذون نفس الترتيب)
- رسم بياني بالأعمدة لعدد الطلاب في كل مستوى (للفصل وللصف)
- تحليلات إضافية: المتوسط، الوسيط، الانحراف المعياري، نسبة الاجتياز، مقارنة الفصول، توزيع النسب، الأوائل، الطلاب الذين يحتاجون متابعة
- تصدير النتائج إلى Excel وطباعة التقرير

## النشر على Render
المستودع يحتوي `render.yaml`؛ عند ربطه بـ Render كخدمة Web Service تُقرأ الإعدادات تلقائيًا:
- Build: `pip install -r requirements.txt`
- Start: `gunicorn app:app`
