# نظام تحليل درجات الصف السادس — ثيم وزارة التعليم

## التشغيل
```
pip install -r requirements.txt
python make_sample.py      # (اختياري) ينشئ بيانات تجريبية sample_grades.xlsx
python app.py
```
ثم افتحي المتصفح على: http://127.0.0.1:5000

## شكل ملف الإكسل
ثلاثة أعمدة (الأسماء تُكتشف تلقائيًا بالعربي أو الإنجليزي):

| اسم الطالب | الفصل | الدرجة |
|-----------|-------|--------|
| محمد أحمد | 6/ج   | 45     |

يمكن تحميل نموذج جاهز من زر "تحميل نموذج إكسل جاهز" في الصفحة.

## الميزات
- إدخال الدرجة الكلية وحساب النسبة المئوية لكل طالب
- تصنيف المستويات (ممتاز / جيد جدًا / جيد / مقبول / غير مجتاز) بحدود قابلة للتعديل
- ترتيب الطلاب على مستوى الفصل وعلى مستوى الصف كامل (المتساوون يأخذون نفس الترتيب)
- رسم بياني بالأعمدة لعدد الطلاب في كل مستوى (للفصل وللصف)
- تحليلات إضافية: المتوسط، الوسيط، الانحراف المعياري، نسبة الاجتياز، مقارنة الفصول، توزيع النسب، الأوائل، طلاب يحتاجون متابعة
- تصدير النتائج إلى Excel + طباعة التقرير
