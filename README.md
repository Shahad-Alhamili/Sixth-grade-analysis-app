# نظام تحليل درجات الصف السادس — ثيم وزارة التعليم

تطبيق ويب (Flask + HTML) يحلل درجات طلاب الصف السادس: نسب مئوية، مستويات، ترتيب على مستوى الفصل والصف، رسوم بيانية، وتصدير للنتائج.

## التشغيل محليًا
```
pip install -r requirements.txt
python make_sample.py      # اختياري: ينشئ ملفات بيانات تجريبية
python app.py
```
ثم فتح المتصفح على: http://127.0.0.1:5000

## التبويبات
- **تحليل الدرجات والشهادات**: رفع ملف الدرجات، التقرير الإحصائي، الترتيب، الرسوم،
  وشهادات التفوق المبنية على الدرجات.
- **شهادات الشكر والمشاركة**: شهادات لا تعتمد على درجات. تُلصق الأسماء نصًا (اسم لكل سطر،
  ويمكن إتباعه بفاصلة ثم الفصل) أو يُرفع ملف Excel عبر المسار `/names`. تتوفر مناسبات
  جاهزة قابلة للتعديل مع الرموز `{الاسم}` و`{الفصل}` و`{البرنامج}` و`{المدرسة}`،
  ونمطَا زخرفة: عامة (رايات ووسام وكأس) ودراسية (آلة حاسبة ودفتر).
  يمكن رفع كشف الطالبات اختياريًا لاستكمال الأسماء الثنائية إلى أسمائها الكاملة
  عبر المسار `/expand_names`: يُبحث داخل فصل الطالبة أولًا ثم في الكشف كله،
  ويُقبل الاسم الكامل إذا وردت كلمات الاسم المختصر داخله بالترتيب نفسه. عند تعدد
  المرشحين يبقى الاسم كما هو ويُعرض المرشحون للمراجعة بدل الاختيار العشوائي.

- **من لم تختبر**: يُرفع كشف الطالبات الكامل وملف درجات الاختبار، فتُطابَق الأسماء ويظهر
  من لم تختبر مجمّعًا حسب الفصل، مع إحصائية غياب لكل فصل وتصدير Excel وطباعة.
  المطابقة على ثلاث مراحل: تطابق تام بعد توحيد الهمزات والتاء المربوطة وحذف «بنت»،
  ثم تطابق مجموعة الكلمات بصرف النظر عن ترتيبها، ثم تشابه نصي بحد ٠٫٨٨. المرحلتان
  الأخيرتان تُعرضان في قائمة «تطابق يحتاج مراجعة»، وتُعرض كذلك الأسماء الموجودة في
  ملف الدرجات دون مقابل في الكشف.

لوحة «بيانات المدرسة والتقرير» مشتركة بين التبويبات وتغذّي الترويسة والتذييل.

## صيغة ملف الدرجات
الصيغة الأولى — شيت لكل فصل (اسم الشيت هو اسم الفصل):

| اسم الطالب | الدرجة |
|-----------|--------|
| محمد أحمد | 45     |

الصيغة الثانية — شيت واحد بعمود إضافي للفصل:

| اسم الطالب | الفصل | الدرجة |
|-----------|-------|--------|
| محمد أحمد | 6/ج   | 45     |

- أسماء الأعمدة تُكتشف تلقائيًا بالعربي أو الإنجليزي.
- لا يشترط أن يبدأ الجدول من الصف الأول: تُفحص أول ثلاثين صفًا ويُختار صف الأعمدة
  تلقائيًا، فتُتجاوز العناوين التمهيدية والصفوف الفارغة. يُعرض أسفل زر الإنشاء ملخص
  لما تعرّف عليه النظام (رقم صف العناوين، الأعمدة، ومصدر الفصل) للمراجعة.
- إذا كان عمود الفصل يحتوي خلايا مدموجة، تُكمَّل القيمة الفارغة من الصف الذي قبلها.
- الأرقام العربية (٤٥) مقبولة.
- زر "تحميل نموذج إكسل جاهز" في الصفحة يوفر ملفًا بالصيغة الأولى.

## الشعار
لإظهار شعار وزارة التعليم في التقرير والشهادات، يوضع ملف باسم `logo` في مجلد `static`
أو في مجلد المشروع، بأي امتداد مدعوم (png, jpg, jpeg, svg, webp, gif).

يُقدَّم الشعار عبر المسار `/logo` بعد إزالة خلفيته البيضاء آليًا وتحويلها إلى شفافة،
مع تنعيم الحواف. تُزال المساحات الفاتحة المتصلة بحواف الصورة فقط، فلا تتأثر
المساحات البيضاء داخل الشعار. المسار `/logo?raw=1` يُرجع الملف الأصلي دون معالجة.
ملفات SVG تُقدَّم كما هي. عند غياب الملف يُعرض اسم الوزارة كنص بديل.

شهادات ثيم اليوم الوطني تعرض صورتين إضافيتين أعلى يسار الشهادة:

| المسار | المحتوى | أسماء الملفات المقبولة |
|--------|---------|------------------------|
| `/emblem` | شعار المملكة (النخلة والسيفان) | emblem، شعار، نخلة |
| `/flag` | علم المملكة | flag، علم، saudi-flag |

الصورتان تمران بنفس معالجة إزالة الخلفية، وعند غياب أي ملف يُخفى العنصر
تلقائيًا دون أثر على بقية التصميم.

## الميزات
- إدخال الدرجة الكلية وحساب النسبة المئوية لكل طالب
- تصنيف المستويات (ممتاز / جيد جدًا / جيد / مقبول / غير مجتاز) بحدود قابلة للتعديل
- ترتيب الطلاب على مستوى الفصل وعلى مستوى الصف كامل (المتساوون يأخذون نفس الترتيب)
- رسم بياني بالأعمدة لعدد الطلاب في كل مستوى (للفصل وللصف)
- تحليلات إضافية: المتوسط، الوسيط، الانحراف المعياري، نسبة الاجتياز، مقارنة الفصول، توزيع النسب، الأوائل، الطلاب الذين يحتاجون متابعة
- تقرير بتنسيق نموذج تحليل النتائج المعتمد (صفحات A4 جاهزة للطباعة)
- تصدير PDF مع اختيار الأقسام المضمّنة، وتصدير Excel، وطباعة مباشرة
- شهادات تلقائية (A4 عرضي) بخمسة ثيمات: نافس، اليوم الوطني، بنفسجي، وردي، تركوازي
- تصفية الشهادات حسب الفصل، واختيار المستحقين: الحاصلون على ممتاز أو كل من اجتاز
- ثيم نافس يعتمد قالب `static/cert-nafs.jpg` ويعبّئ فوقه: اسم الطالبة والفصل،
  اسم المعلمة، اسم المديرة، والتاريخ
- نصوص الشهادات والتقارير بصيغة المؤنث ثابتة
- اسم المعلمة ومديرة المدرسة يُدخلان يدويًا ويظهران في تذييل كل صفحة

## النشر على Render
المستودع يحتوي `render.yaml`؛ عند ربطه بـ Render كخدمة Web Service تُقرأ الإعدادات تلقائيًا:
- Build: `pip install -r requirements.txt`
- Start: `gunicorn app:app`
